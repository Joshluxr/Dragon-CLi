## @Dragon on Slack

<Callout type="info">
  To mention @Dragon on Slack, you must first connect your Slack workspace in [Settings](https://dragon-labz.vercel.app/settings/integrations).
</Callout>

### How It Works

Mention `@Dragon` in Slack to create new Dragon tasks. Dragon will kick off a new task with the context of the message and respond with a link to the task created. When used in threads, dragon will include the thread context as well.

### What Happens

When you mention `@Dragon`:

<Steps>
  <Step>A new task is created automatically with the context of the message</Step>
  <Step>
    For messages in threads, Dragon will include the full thread context.
  </Step>
  <Step>
    Dragon will respond with a link to the task created
  </Step>
  <Step>Work begins in an isolated sandbox</Step>
  <Step>
    You'll see the task appear in [<House className="inline-block w-4 h-4 mx-1" /> **Home**](https://dragon-labz.vercel.app)
  </Step>
</Steps>

### Configuration

You can configure the default repository and model for Dragon to use when creating tasks in Slack after connecting your workspace in [Settings](https://dragon-labz.vercel.app/settings/integrations).
